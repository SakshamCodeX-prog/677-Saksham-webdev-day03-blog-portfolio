## Overview

This is my Day 3 Web Development project — a personal blog and portfolio website built using HTML and CSS. It showcases my introduction, learning journey, and blog posts through a clean and responsive design.

## What I Built

- Created a personal homepage with an introduction.
- Added an About page with my education and background.
- Created a Blog page to share learning experiences and notes.
- Used semantic HTML elements to structure the pages.
- Added images and illustrations with appropriate alt text.
- Used external links with `target="_blank"` and `rel="noopener noreferrer"`.
- Styled the website using CSS.
- Added navigation links between all three pages.
- Made the website responsive for different screen sizes.
